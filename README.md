# Hospital Financial and Operational Dashboard

## Project Overview

This project analyzes hospital financial and operational performance using Power BI.

The dashboard was developed to provide insights into revenue generation, profitability, patient activity, doctor performance, and specialty performance.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling

## Skills Demonstrated

- Data Cleaning
- Data Modeling
- Power Query
- DAX Measures
- KPI Development
- Dashboard Design
- Data Visualization

## Data Model

The solution was built using a star schema model consisting of:

- Fact_Transactions
- Dim_Date
- Dim_Doctors
- Dim_Patients
- Dim_Location
- Dim_Procedures

## Key KPIs

- Total Revenue
- Total Expenses
- Total Profit
- Profit Margin
- Number of Doctors
- Number of Patients

## Dashboard 1: Financial Overview

This dashboard focuses on financial performance and includes:

- Revenue by Specialty
- Revenue and Expenses by Month
- Procedure Financial Breakdown
- Revenue by Category

## Dashboard 2: Operational Overview

This dashboard focuses on patient and doctor activity and includes:

- Top Doctors by Revenue
- Top Patients by Revenue
- Gender Distribution
- Patient Visits by Month
- Specialty Analysis

## Key Insights

- Dermatology and Cardiology generated significant revenue contributions.
- Revenue remained relatively stable across the year.
- Patient activity remained consistent across months.
- Revenue generation was concentrated among a small number of doctors and patients.
- Specialty performance varied considerably across the hospital.
